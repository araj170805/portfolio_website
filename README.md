## How to Open Locally
### Method 1: Simple Browser Open
1. Clone or download the repository  
2. Make sure all files are in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`
   - 'ashish.jpeg'
3. Open `index.html` in any modern web browser  
4. CSS styles and JavaScript functionality will load automatically

---

### Method 2: Using Live Server (Recommended)
1. Open the project folder in **VS Code**
2. Ensure these files exist:
   - `index.html`
   - `style.css`
   - `script.js`
   - 'ashish.jpeg'
3. Install **Live Server** extension
4. Right-click `index.html` → **Open with Live Server**
5. Animations, dark mode, and sound effects will work smoothly

## Deployment

The website is deployed on **GitHub Pages**:

- Go to **Settings → Pages**
- Select `main` branch and root folder
- Save and get the live link
